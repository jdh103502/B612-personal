# 양 카드와 싹 먹기 시제품

2026-10-30. `GameDesign.md`의 후속 사용자 요청을 구현했다. 씬은 `Assets/B612/Scenes/B612_EmptyPlanet.unity`이며, 행성 지형과 이동·중력은 그대로 사용한다.

## 역할

- `LambCardHand`: 카드 소유권, 숫자·휠 선택, Q 소환, 지면 배치, 싹 예약, 회수 시 카드 반환을 담당한다. 같은 양을 중복으로 소환하거나 회수할 수 없다.
- `LambAgent`: `Grazing → Pickup → Collected` 상태와 20초 활동·10초 먹기를 담당한다. 지면의 소환 위치에 머물며 대상 방향을 바라보고 가볍게 움직인다. 아직 자유 이동 AI나 경로 탐색은 없다.
- `LambCardHUD`: 원본 프레임·일러스트를 사용한 부채꼴 손패다. 선택 카드는 위로 올라오고, 소환한 카드는 빠진다. 남은 카드만으로 손패를 다시 정렬한다. 숫자는 원래 카드의 1~4번을 유지한다.
- `LambEatingIndicators` / `EatingProgressGraphic`: 먹는 양의 머리 위에 실제 먹기 진행도를 시계 방향 파이로 표시한다. 대기·먹기 완료·아이템 전환·회수 시 숨기고, 행성에 가려진 양이나 화면 밖까지 표시하지 않는다. 다음 싹을 먹으면 해당 싹의 진행도로 다시 시작한다.
- `SproutHorizonIndicators`: 기존 싹 표시와 함께 회수용 양을 추적한다. 회수 아이템은 크림색 양 아이콘과 금빛 테두리를 사용하며, 직접 보이면 숨기고 가려지면 지평선 방향에 표시한다.
- `OrbitCamera.cardInputMode`: 새 씬에서만 Q와 휠을 카드에 양보한다. 다른 데모 씬은 원래 Q/E·휠 카메라 조작을 유지한다.
- `LambPrototypeBuilder.Build`: 프리팹·재질·스프라이트 설정과 씬 연결을 Unity CLI `run_script`로 구성한다. 기존 바오밥 빌더와 분리했다.

## 입력과 수명

- 휠 또는 숫자 1~4: 손패에서 선택. 이미 소환된 카드는 선택하지 않는다.
- Q: 지면에 선택한 양 소환. 공중이거나 유효한 공간이 없으면 카드를 소비하지 않는다.
- 카메라: 마우스 드래그 / Z·C, Ctrl+휠 줌.
- 20초 동안 사용한 카드는 손패에 없다. 만료된 양은 0.22초에 걸쳐 27%로 작아지고 약 0.2m 높이에서 회전·상하 움직임을 보인다.
- 최소 0.8초 뒤 플레이어가 원래 소환 위치의 0.9m 이내로 오면 같은 카드 슬롯에 반환한다. 멀리 있으면 아이템으로 남는다. 자동 원격 반환이나 새 카드 복제는 없다.
- 양의 활동·먹기·아이템 움직임은 게임 시간에 따른다. 일시정지 시 함께 멈춘다.

## 먹기 범위와 의도 보정

기본 1.7m는 양 소환 위치에서 측정한다. 거리 경계에 0.25m의 작은 여유를 둔다. 행성 중심 기준 각도와 평균 반경으로 표면 거리를 근사해 행성 반대쪽을 관통하는 단순 직선 거리 판정을 피한다. 실제 메시의 최단 경로를 계산하는 시스템은 아니다.

배치는 플레이어 앞 약 0.85m를 기본으로 한다. 플레이어 주변 2.05m 이내의 가까운 싹 중 대체로 전방에 있는 미예약 싹을 우선하며, 그 싹에서 약 0.55m 떨어진 쪽으로 지면 배치를 보정한다. 양끼리 너무 겹치는 지점과 심한 경사는 피하고, 보정 후에도 의도한 싹이 먹기 범위 밖이면 그 위치에는 소환하지 않는다. 카드와 자원을 먼저 소비한 뒤 실패하는 방식은 사용하지 않는다.

선택한 카드가 있고 접지 중이면 예상 먹기 원을 지면에 표시한다. 의도 대상으로 잡은 싹은 작은 금색 원으로 표시한다. 소환한 양의 범위는 더 흐린 원으로 남는다.

양은 유효한 싹 하나를 예약하고 10초간 먹는다. 다른 양은 같은 싹을 중복 예약하지 않는다. 대상이 사라지거나 범위를 벗어나면 그 먹기 진행은 초기화하고 다른 가까운 싹을 찾는다. 먹을 싹이 없는 시간은 활동 시간에 포함하지만 먹기 진행에는 포함하지 않는다. 따라서 근처에 싹이 충분하면 20초에 최대 2개를 먹고, 없으면 적게 먹는다. 20초 경계의 두 번째 먹기는 만료 전에 완료한다.

먹기 완료는 기존 `BaobabSurge.RemoveSprout`를 호출한다. 활성 6개 상한의 빈자리와 지평선 말풍선도 기존 흐름으로 갱신된다. 폭주 시간이 끝났어도 남은 싹을 양이 먹고 아이템을 회수할 수 있다.

2026-10-31 위험도 연동: 먹는 중인 싹도 위험량을 유지하며 성장한다. 먹기 완료 후에만 해당 기여도가 사라진다. 같은 프레임의 먹기 완료를 반영한 뒤 위험도 100%를 판정한다. 게임 오버가 확정되면 먹기·아이템 회수·신규 소환을 정지한다. 재시도는 씬 전체를 다시 불러 카드 4장과 빈 행성 상태로 돌아간다.

## 진행 UI와 거리별 말풍선

양의 현재 먹기 대상 싹은 지평선 말풍선에서 제외한다. 양이 대상을 놓거나 비활성화·만료되어 먹기가 중단되면, 남아 있는 싹은 다음 UI 갱신부터 다시 일반적인 가림 판정에 따라 안내한다.

진행 파이는 `EatingProgress / secondsPerSprout`을 그대로 표시한다. 10초 중 5초를 먹었으면 원의 절반이 찬다. 양 수명 타이머와 별개이며 먹을 싹이 없을 때는 표시하지 않는다. 지면 Collider로 양의 상체가 가려졌는지 확인해 지평선 너머로 진행 표시가 새지 않게 한다.

말풍선의 크기는 화면에 붙이는 지평선 지점까지의 거리가 아니라 **플레이어에서 실제 대상까지의 표면 거리 근사**를 사용한다. 싹과 회수용 양에 같은 곡선을 적용한다. 초기값은 1.5m 이내에서 1.2배, 12m 이상에서 0.62배이며 중간은 부드럽게 보간하고 상하한을 둔다. 카메라 줌만 바꿨을 때 플레이어와 대상의 거리 의미가 달라지지 않도록 카메라 거리 대신 플레이어 거리를 쓴다.

말풍선 위치·간격·가장자리 여백도 크기를 반영하고, 꼬리의 로컬 좌표를 스케일로 나누어 지평선 방향을 계속 가리키게 한다. 회수 완료·삭제 시 해당 말풍선도 사라진다. `LambPrototypeBuilder.AddFeedbackUI`로 기존 씬에 덧붙일 수 있고, `Build`도 같은 구성을 포함한다.

## 검증

`AgentScripts/LambPrototypeValidation.cs`는 Play 모드에서만 임시 지면 배치로 검증한다. 종료 시 싹 배치와 플레이어 상태를 초기화한다.

- 9.99초에는 싹 유지, 10초에 첫 싹 제거 및 활성 개수 감소.
- 20초에 두 번째 싹 제거와 아이템 상태 전환. 먹기 대상을 공유하는 중복 예약 방지.
- 배치 의도 보정 후 싹까지 약 0.56m. 기본 범위 가장자리 바깥인 1.82m도 작은 여유 범위 안에서 먹고, 2.3m의 싹은 유지.
- 가까이 있어도 0.8초 전에는 아이템을 즉시 회수하지 않음. 회수 후 카드 4장 복원, 중복 반환 거절.
- 공중 소환 거절 시 카드 수 보존.
- 가상 키보드·마우스로 숫자 3 선택 → 휠로 4번 선택 → Q로 실제 소환을 확인. 일반 휠 선택 중 카메라 줌이 변하지 않음.
- 실제 시간 경과 후 20초 만료·시각 스케일 0.27·회전을 확인했고, W로 접근하여 양이 사라지고 손패가 3장에서 4장으로 복원되는 흐름을 확인했다.
- `LambFeedbackValidation`: 화면에 그려진 파이 50% 확인, 지평선 뒤 진행 표시 억제, 먹기 완료·대기·아이템 상태에서 진행 숨김, 숨은 회수 아이템의 지평선 계산, 직접 보이는 회수 아이템의 말풍선 억제를 통과했다. 0~30m의 121개 거리에서 크기 곡선의 단조 감소와 상하한을 검사했다.
- 행성 반대편에서 실제 양 아이콘 말풍선과 0.62배 크기를 확인하고, 회수 후 카드 복원과 양 말풍선 개수 0을 확인했다. 기존 지평선 검증도 함께 실행한다.

네 장·세부 거리·시각 크기는 이번 시제품의 조절 가능한 값이다. 양 종류·특성·최종 밸런스와 전체 게임의 진행 규칙은 아직 별도 설계 대상이다.
