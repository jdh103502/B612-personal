# B612

『어린왕자』와 『슈퍼마리오 갤럭시』를 축으로 한, 우주 배경의 카툰풍 3D 플랫포머 컨셉 데모입니다.
작은 행성마다 중력이 있어서 행성을 한 바퀴 걸어서 돌 수 있고, 약한 중력 속에서 점프하며 행성 사이를 건넙니다.

목표 게임의 기본 기획과 검토 사항은 [기본 게임 기획](Docs/GameDesign.md)에 정리되어 있습니다. 아래는 현재 컨셉 데모의 안내입니다.

![밤 전경](Assets/Captures/B612_Night.png)

   ```
   git lfs install
   ```

   ```
   git clone https://github.com/hpc99jtzqd-dot/B612.git
   ```
3. **Unity Hub에서 열기** — 반드시 같은 버전 **Unity 6000.3.23f1** (Unity 6.3, URP)로 엽니다.
   처음 열 때는 Library 폴더를 새로 만드느라 몇 분 걸립니다.

### 자연 지형과 3챕터

`Assets/B612/Scenes/B612_ChapterJourney.unity`를 열고 Play합니다. **금색 기둥에 다가가 E**로 1챕터 대쉬 → 2챕터 더블점프 → 3챕터 활공을 배웁니다. 초록색 작물 조사 지점과 파란색 만남 지점도 E로 방문하며 이동 시간과 거리를 기록합니다.

바오밥 생성 종료 후 **M**으로 연결된 다음 행성을 선택합니다. 각 챕터의 도착 행성에서 생성 종료 후 지도 아래 **다음 챕터** 버튼을 누릅니다. 빠른 비교는 **F12 → 바오밥 페이즈 스킵 → 닫기 → M**입니다. F12 능력 체크박스는 이미 배운 능력만 제어합니다. R·행성 이동은 해금과 개발 허용값을 유지하며 새 Play/패배 재시도는 새 여정입니다.

두 층의 연속 높이장(gradient noise)이 구면 전체에 언덕과 분지를 만들고, 지역마다 잔잔한 초원과 울퉁불퉁한 구역이 나뉩니다. 물이 모이는 경로에는 얕은 마른 도랑이 파이고, 강은 그 경로를 따라 하류로 갈수록 넓어지며(약 0.9m → 최대 3m) 분지의 얕은 연못으로 들어갑니다. 강물은 깊이에 따라 색이 바뀌고 하류로 흐르는 잔물결과 물가 거품이 보이며, 강과 연못의 물속 보행 속도는 65%입니다. 완성된 지면에서 기본 보행으로 연결된 영역을 찾아 스폰·상호작용·바오밥 후보를 배치합니다. 잔디·흙 텍스처와 행성별 색상을 적용하고, 물이 모이는 골짜기와 저지대는 풀이 짙게, 능선은 흙이 드러나게 칠합니다. [지형과 이동 검증](Docs/NaturalPlanetTerrainImplementationResults.md) · [잔디·흙 적용 결과](Docs/GrassDirtTextureAssetImplementationResults.md)

챕터당 6노드 항성계 하나를 사용합니다. 작물 수확·양털·NPC 퀘스트 경제와 중간 저장은 후속 범위입니다. 지형과 강은 각 생성 에셋의 **Natural Terrain**에서 조절합니다. 같은 시드를 비교하려면 씬의 `StarSystemFlowController`에서 `randomizeRunSeed`를 끄고 `runSeed`를 지정한 뒤 새로 Play합니다. 실행 중에는 `ActivePlanetWorld`의 `ProceduralPlanetTerrain`에서 실제 적용값과 배치 결과를 확인할 수 있습니다.

### 이동 지형 실험실 · 1단계

`Assets/B612/Scenes/B612_TraversalTest.unity`를 열고 Play합니다. **1 / 2 / 3**으로 골짜기·높은 턱·활공 구간을 선택하고 **R**로 현재 구간을 다시 연습합니다. 처음에는 확장 능력이 모두 꺼져 있습니다. **민트색 우회로**는 기본 보행만으로 통과할 수 있고, **금색 지름길**은 기존 **F12** 체크박스로 대쉬·추가 점프·활공을 켜 비교합니다. 구간 선택/R은 능력 허용값을 유지합니다.

골짜기는 폭 4.2m·깊이 2m, 턱은 높이 2m, 활공은 기준 구면 간격 7m·출발/착지 높이 2.6/0.4m입니다. 화면에 조작 안내·허용값·구간 시간을 표시합니다. 이 씬은 이동 실험에 집중하며 절차적 생성이나 챕터 해금은 추가하지 않았습니다. [규격·실제 모터와 입력 검증](Docs/TraversalTestCourseStage1Results.md)을 참고하세요.

### 바오밥 스폰 시제품 실행

`Assets/B612/Scenes/B612_EmptyPlanet.unity`를 열고 Play를 누릅니다. 120초 동안 약 3초마다 싹을 생성하되 동시에 존재하는 싹은 최대 6개입니다. 생성 수가 적은 구역을 우선하고 싹 사이에 최소 1.4m 간격을 두어 옆면과 밑면까지 분산합니다. 화면 상단의 바와 숫자로 남은 시간, 현재 활성 수와 누적 생성 수를 확인할 수 있습니다. 아래의 별도 `BAOBAB THREAT` 바가 100%가 되면 게임 오버입니다.

행성에 가려진 싹은 해당 방향의 지평선 근처에 싹 아이콘 말풍선으로 표시됩니다. 싹이 보이면 표시를 숨깁니다. 지평선이 화면 밖인 방향은 화면 가장자리에 표시합니다. 6개가 차면 생성을 건너뛰며, 양이 싹을 먹으면 다음 생성 시점에 빈자리를 채웁니다.

단독 스폰 검증에서는 `Baobab Surge` Inspector의 시간·생성 기회·동시 상한·간격·seed를 사용합니다. 공통 항성계 경로는 확정된 행성 데이터가 해당 값을 주입합니다. `PlanetSurfaceGrid`를 선택하고 Scene 뷰의 Gizmos를 켜면 논리 구역 경계가 보입니다. 기본 1배는 80개, 1.5배는 180개, 2배는 320개로 늘어납니다. 논리 구역과 지형 메시 해상도는 별개입니다.

기준 밀도는 `EmptyPlanetGeneration.asset`의 `subdivisions`(기본 1)로 설정합니다. `PlanetSurfaceGrid` Inspector에는 준비된 frequency·구역·후보 수가 읽기 전용으로 표시됩니다. 구역당 후보는 최대 32개이며 구역 증가로 바오밥 수량이 늘지는 않습니다. [타일 밀도 구현·검증](Docs/PlanetTileDensityImplementationSpec.md)을 참고하세요.

이번 시제품에는 양의 싹 먹기와 카드 회수가 있습니다. 작물·양털·특성·퀘스트·행성 파괴는 아직 구현하지 않았습니다. 40번의 생성 기회·1.4m 등은 첫 테스트용 수치입니다. 세부 구현과 아직 제안 상태인 범위는 [행성 생성 설계](Docs/PlanetGenerationDesign.md)를 참고하세요.

### 바오밥 위험도와 게임오버

- 살아 있는 싹 각각의 위험량은 `min(25, 2 + 0.15×생존 초 + 0.005×생존 초²)`입니다. 합산한 위험량을 행성의 고정 한계량 100으로 나누어 게이지를 표시합니다. 오래된 싹일수록 상한 전까지 빠르게 성장합니다.
- 양이 먹는 동안도 위험량은 증가하며, 먹기가 끝나서 싹이 제거되면 그 싹의 위험량이 사라집니다. 먹는 싹의 말풍선을 숨기는 규칙은 유지합니다.
- 120초는 **신규 생성의 종료 시간**입니다. 이후에도 남은 싹은 성장하고 패배할 수 있습니다. 전부 제거하면 `PLANET SAFE`가 표시되며, 수확 단계로의 이동은 아직 없습니다.
- 100%에서 생성·성장·양 먹기·소환·플레이어 및 카메라 조작을 정지합니다. **TRY AGAIN 버튼 / Enter**로 현재 씬과 카드·타이머·게이지를 초기화합니다.
- `Assets/B612/Settings/PrototypeBaobabProfile.asset`에서 고정 한계량, `BasicBaobab.asset`에서 싹 성장 수치를 조절합니다. 설정은 실행 시작 시 복사되므로 변경한 밸런스는 새 시도부터 적용됩니다. 생성 수량은 계속 `Baobab Surge` Inspector에서 조절합니다.

기본 설정을 방치하면 약 48.47초에 패배합니다. 최종 난이도가 아닌 첫 검증값입니다. 구현 선택과 검증 결과는 [바오밥 위험도 설계](Docs/BaobabThreatDesign.md)를 참고하세요.

### 양 카드 조작

- 하단에 양 카드 4장을 들고 시작합니다. **휠 / 숫자 1~4**로 선택하고 **Q**로 지면에 소환합니다.
- 선택한 카드가 올라오며 예상 먹기 범위가 지면에 표시됩니다. 가까운 싹이 금색 원으로 표시되면 그 싹을 우선으로 배치합니다.
- 양은 20초간 머물고, 범위 안의 **싹 7초 / 묘목 10초 / 나무 13초**에 한 개씩 먹습니다. 기본 범위는 1.7m이고 거리 경계에 작은 여유를 둡니다. 같은 개체는 여러 양이 중복으로 먹지 않습니다. 카드와 소환 예상 대상 안내에도 단계별 시간을 표시합니다.
- 만료된 양은 작아져 약간 떠서 회전합니다. 가까이 걸어가면 회수하고 같은 카드가 손패로 돌아옵니다.
- 먹는 양 위의 원형 파이로 싹 하나를 먹는 진행도를 확인합니다. 지평선 너머나 대기·만료 상태에는 이 진행 표시가 나오지 않습니다.
- 행성 뒤의 회수용 양은 양 아이콘 말풍선으로 안내합니다. 싹·양 말풍선은 실제 대상이 가까우면 크게, 멀면 작게 보입니다.
- 이 씬의 카메라는 **마우스 드래그 / Z·C**, 줌은 **Ctrl+휠**입니다. 다른 데모 씬의 조작은 아래 기존 표를 따릅니다.

시간·먹기 범위·초기 카드 수는 `Lamb Card Hand` Inspector에서 조절할 수 있습니다. [양 시제품 설계와 검증](Docs/LambPrototypeDesign.md)에 소스와 동작 기준을 정리했습니다.

바오밥은 생성 후 **20초에 묘목, 40초에 나무** 모델로 바뀝니다. 이 시점과 모델 프리팹은 `Assets/B612/Settings/BasicBaobab.asset`에서 조절합니다. 먹는 도중에는 성장 시점을 지나도 모델과 먹는 시간이 유지되며, 먹기가 중단되면 실제 나이에 맞춰 다시 성장합니다. 이때 위험도는 계속 증가합니다.

카메라는 행성 중심을 기준으로 자세를 유지하고, 일반 점프에는 자동 줌·공중 자동 회전을 적용하지 않습니다. 점프 높이는 일정 여유 안에서 화면 속 움직임으로 보여주며, 큰 상승·낙하만 추적합니다. 장애물에 접근하면 즉시 안전 거리로 당기고 천천히 복귀합니다. 수동으로 조절한 시야 각도도 유지합니다. 조절값과 전후 비교는 [카메라 안정화 설계와 구현](Docs/CameraStabilityDesign.md)을 참고하세요.

### 플레이어 이동 확장

`B612_EmptyPlanet`의 Player에 더블점프·대쉬·활공을 연결했습니다.

| 입력 | 동작 |
| --- | --- |
| Space 누름 | 즉시 점프, 공중에서 다시 누르면 추가 점프 1회 |
| Left / Right Shift | 캐릭터가 바라보는 방향으로 지상·공중 대쉬 |
| Space 0.2초 이상 유지 + 하강 | 활공, 공중 구간당 총 2.5초 |
| 패드 South / Right Shoulder | 점프·유지 / 대쉬 |

추가 점프와 공중 대쉬는 각각 착지 전 1회이며, 대쉬나 활공을 반복해도 회복되지 않습니다. 안정적으로 착지하면 다시 사용할 수 있습니다. 대쉬는 약 0.18초·최고 8m/s·쿨다운 0.65초입니다. 조절값은 Player의 `PlayerTraversalAbilities` Inspector에 있으며 [이동 명세와 구현·검증 기록](Docs/PlayerTraversalImplementationSpec.md)을 참고하세요.

### 항성계 지도와 행성 이동

**바오밥 생성 시간이 끝나면 M 지도**가 활성화됩니다. 지도에서 마우스를 올려 행성 크기(소·중·대)를 확인하고, 밝은 테두리의 연결된 행성을 클릭하면 이동합니다. **M / Esc / 닫기**로 지도를 닫습니다. 지도 안에서는 게임 시간이 정지하며 F12 디버그와 동시에 열리지 않습니다.

첫 항성계는 6개 노드의 고정 분기입니다. 시작은 1배 모래색, 새 행성은 기준 반경의 **0.7~2배 크기와 파스텔 색**으로 생성됩니다. 크기·색·seed는 여정 시작 때 확정되고, 해당 seed로 준비한 저주파 지형도 지도 재열기로 바뀌지 않습니다. 플레이어·양·싹의 크기와 이동 수치는 유지합니다.

남은 바오밥을 두고 출발할 수 있지만 위험도 100%의 게임오버가 우선합니다. 이동하면 배치했던 양은 같은 카드로 돌아오고 새 행성의 생성 타이머가 시작됩니다. F12 허용 설정은 유지됩니다. 마지막 행성의 생성 종료 후에는 테스트 항성계 완료를 표시하며, 남은 바오밥은 계속 성장합니다. R은 현재 행성의 리스폰이고 게임오버 재시도는 새 여정입니다.

`StarSystemFlow`의 seed/전환 시간과 `Assets/B612/Settings/PlanetTravel/EmptyPlanetGeneration.asset`의 팔레트·지형 설정을 확인할 수 있습니다. 생성 시간과 수량은 행성 데이터의 기본값을 사용하므로 120초·40회·동시 6개를 유지합니다. 지도는 [구현·검증 기록](Docs/StarSystemMapTravelImplementationSpec.md), 지형은 [자연 지형 적용 결과](Docs/NaturalPlanetTerrainImplementationResults.md)를 참고하세요.

### 개발자 디버그 모드

`B612_EmptyPlanet`을 Editor 또는 Development Build에서 실행한 뒤 **F12**로 열면 게임이 일시정지됩니다. **대쉬·더블점프·활공** 체크박스를 각각 켜거나 끌 수 있습니다. F12 재누름 또는 **닫기 · 계속하기**로 돌아갑니다.

**바오밥 페이즈 스킵** 버튼은 현재 행성의 생성과 잔여 바오밥을 정리하고 배치한 양을 같은 카드로 돌려받습니다. 시간·생성 통계·이동 자원을 진행시키지 않으며 디버그 정지를 유지합니다. **닫은 뒤 M**으로 다음 행성을 선택하세요. 게임오버 상태에서는 사용할 수 없고 다음 행성은 정상 페이즈로 시작합니다. 구현과 최소 검증 기록은 [바오밥 페이즈 스킵 명세](Docs/DeveloperBaobabSkipImplementationSpec.md)를 참고하세요.

열기만 하면 진행 중인 기술과 남은 자원을 보존하며, 체크 변경으로 자원이 충전되지 않습니다. 같은 시도의 R 리스폰에는 설정이 유지되고 새 Play·게임오버 재시도에서는 모두 켜짐으로 시작합니다. 게임오버 중에도 열 수 있지만 닫아도 패배 정지는 유지됩니다. [구현과 검증 기록](Docs/DeveloperDebugModeSpec.md)을 참고하세요.

## 폴더 구조

```
Assets/B612/
  Scenes/      씬
  Scripts/     게임 코드 (중력, 이동, 카메라, 애니메이션, 집 내부, 발사 별 …)
  Shaders/     밤하늘, 반딧불 셰이더
  Models/      왕자(Meshy), 여우(Blender) 모델
  Generated/   빌더가 만든 메시·재질·프리팹 (직접 수정하지 말 것)
AgentScripts/  씬과 모델을 생성하는 스크립트
  B612Builder.cs           씬 전체를 다시 만드는 빌더 (Unity CLI로 실행)
  blender/                 캐릭터 모델 생성 스크립트 (Blender 5.2)
  runtime/                 Assets/B612/Scripts 원본
```

> 씬과 `Generated/` 는 `AgentScripts/B612Builder.cs` 가 처음부터 다시 만듭니다.
> 씬을 손으로 수정한 뒤 빌더를 다시 실행하면 수정 내용이 덮어써지니, 이 점을 맞춰서 작업해 주세요.
